# Fiend Control Panel

Starter project for a classroom lab.

## Run locally

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

## Render

Create a Node Web Service from this repository. Build command:

```text
npm install
```

Start command:

```text
npm start
```

The server listens on `0.0.0.0` and uses Render's `PORT` environment variable.

This starter intentionally does not implement remote camera, microphone, SMS, file extraction, or hidden device-control commands.
